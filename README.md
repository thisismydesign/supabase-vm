# supabase-vm

Self-hosted Supabase, one VM per project, on the personal dev server. The VM is the boundary: whatever happens on the host (tool installs, Docker restarts, agents) does not reach it.

- **VM** — incus on the host, Ubuntu cloud image, fixed CPU, memory and disk, autostart.
- **Supabase** — the official self-hosting bundle inside the VM, keys generated by its own scripts, Docker publishing on localhost only.
- **Access** — Tailscale inside the VM. The API is public through Tailscale Funnel at `https://<vm>.<tailnet>.ts.net`; Postgres is tailnet-only on 5432; SSH is Tailscale SSH. No port is opened on the host.

## Host, once

```sh
git clone https://github.com/thisismydesign/supabase-vm ~/workspace/thisismydesign/supabase-vm
```

`host/create-vm.sh` installs incus and the firewall rules on first use.

## Per project

```sh
host/create-vm.sh supabase-<project> https://<frontend-url>   # creates the VM and starts the stack
# approve the printed Tailscale login URL, then:
incus exec supabase-<project> -- /opt/supabase-vm/expose.sh      # Funnel for the API, tailnet TCP for Postgres
```

Keys and passwords live in `/opt/supabase/.env` inside the VM only. Read them with `incus exec supabase-<project> -- cat /opt/supabase/.env`.

## Deploying a project to it

From the host, in the project checkout:

```sh
supabase db push --db-url "postgresql://postgres.<tenant>:<password>@supabase-<project>:5432/postgres"
~/workspace/thisismydesign/supabase-vm/host/deploy-functions.sh supabase-<project> supabase/functions
```

The frontend gets `SUPABASE_URL=https://supabase-<project>.<tailnet>.ts.net` and the publishable key from `.env`.

## Operate

| Task       | Command                                                                      |
| ---------- | ---------------------------------------------------------------------------- |
| Shell      | `incus exec supabase-<project> -- bash` on the host, or `ssh ubuntu@supabase-<project>` over Tailscale |
| Studio     | `https://supabase-<project>.<tailnet>.ts.net`, dashboard user and password from `.env`  |
| Snapshot   | `incus snapshot create supabase-<project> before-<change>`                   |
| Roll back  | `incus snapshot restore supabase-<project> before-<change>`                  |
| Upgrade    | `incus exec supabase-<project> -- bash -c 'cd /opt/supabase && sh update.sh'` |
| Logs       | `incus exec supabase-<project> -- docker compose -f /opt/supabase/docker-compose.yml logs -f` |
